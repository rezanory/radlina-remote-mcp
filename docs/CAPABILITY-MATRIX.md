# Capability matrix

All tools require an authenticated identity. `admin` satisfies narrower scopes, but local kill/read-only controls still win.

| Group                    | Tools                                                                                                                                                                             | Scope                                | Mutation/idempotency                          | Main server-side controls                                                                                               |
| ------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------ | --------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| Device                   | `who_am_i`, `list_devices`, `ping`, `get_capabilities`, `health`, `version`                                                                                                       | `device:read`                        | Read-only                                     | bearer validation, issuer/audience/expiry/scopes                                                                        |
| Filesystem read          | `list_directory`, `read_file`, `read_multiple_files`, `get_file_info`                                                                                                             | `filesystem:read`                    | Read-only                                     | canonical roots, size/page limits, UNC/device/ADS/reserved-name rejection                                               |
| Filesystem write         | `create_directory`, `write_file`, `edit_block`, `copy`                                                                                                                            | `filesystem:write`                   | Key required                                  | atomic writes, exact-match edit, recheck before mutation, link-tree rejection                                           |
| Filesystem destructive   | `move`                                                                                                                                                                            | `filesystem:write`                   | Key required                                  | no overwrite, containment, destructive annotation                                                                       |
| Recoverable delete       | `trash`                                                                                                                                                                           | `admin`                              | Key and exact canonical confirmation required | disabled in default profile, quarantine instead of permanent delete                                                     |
| Search                   | `start_search`, `search_status`, `search_results`, `cancel_search`                                                                                                                | `filesystem:read`                    | Cancel key required                           | pinned ripgrep path, bounded runtime/output/results, owner-bound durable session                                        |
| Process read             | `list_processes`, `read_process_output`                                                                                                                                           | `process:read`                       | Read-only                                     | owner-bound output cursor, bounded output                                                                               |
| Process execution        | `start_process`, `interact_with_process`                                                                                                                                          | `process:execute`                    | Key required                                  | exact executable/argument/env allowlists, no shell, timeout, session cap                                                |
| Process termination      | `terminate_process`                                                                                                                                                               | `process:execute`; `admin` for force | Key required                                  | PID start-time/path identity verification, process-tree termination                                                     |
| Configuration            | `get_effective_config`, `validate_config`, `simulate_policy`                                                                                                                      | `admin`                              | Read-only/simulation                          | strict schema, no secret fields, no remote apply tool                                                                   |
| Diagnostics              | `recent_tool_calls`, `resource_stats`, `error_details`                                                                                                                            | `admin`                              | Read-only                                     | redacted bounded output                                                                                                 |
| Sessions/readiness       | `active_sessions`, `readiness`                                                                                                                                                    | `process:read` / `device:read`       | Read-only                                     | caller ownership, local safety-control state                                                                            |
| Release administration   | `admin_stage_release`, `admin_verify_release`, `admin_upgrade_preflight`, `admin_activate_release`, `admin_upgrade_status`, `admin_rollback_release`, `admin_verify_post_restart` | `admin`                              | Activation/rollback/stage require durable key | exact immutable manifest/file set, path/reparse rejection, mutation lock, health-confirmed restart, ROOT-aware rollback |
| Trusted-owner activation | `admin_enable_trusted_owner`                                                                                                                                                      | `admin`                              | Durable key; atomic config write and restart  | `C:\` root, direct executable access, trash, raised bounded limits; auth/audit/kill/read-only/path validation retained  |

The shipped example remains default-deny. In the owner-authorized production profile, `allowShell: true` deliberately means direct executable access even when `commands: []`; argument NUL/size checks, `shell:false`, environment allowlisting, authentication, scope, kill-switch, emergency-read-only, and audit controls still apply.
